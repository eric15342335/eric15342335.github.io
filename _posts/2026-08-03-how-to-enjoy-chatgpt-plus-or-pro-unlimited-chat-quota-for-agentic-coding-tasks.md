## Preface and Background Context

We all know that:

- [Codex][codex] (or [ChatGPT Work][chatgpt-work]) has a weekly quota.
- The weekly quota cannot sustain long-term [GPT-5.6 Sol][gpt-5.6-sol]
  model usage with `reasoning_level=high`. Unless [OpenAI][openai]
  [resets][codex-resets] your usage quota, you will probably run out of quota
  within one or two days of eight-hour coding sessions.
- [ChatGPT Chat][chatgpt] mode has an unlimited GPT-5.6 Sol High quota for
  [Plus ($20)][chatgpt-plus] or [Pro ($200)][chatgpt-pro] plans.
  - Actually, it is not unlimited, but I have never hit that quota with four
    or five concurrent prompting sessions with conversations of more than five
    turns and more than ten tool-use or [MCP][mcp] calls.
  - I suspect that OpenAI might have a hidden `/compact` instruction directive
    after some threshold of turns is reached. However, this is just a
    hypothesis.
- The associated sandbox has no internet access and cannot install any
  packages. However, it can use preinstalled packages, such as the typical
  [Python][python] data-science bundle and some [npm][npm] packages.
- You can add your own MCP server with [Developer Mode][developer-mode]
  enabled.
- The [Model Context Protocol (MCP)][mcp] is a way to pass information to and
  from external systems, such as your [VPS][vps].
- You have your own VPS with [root access][root-access], unrestricted internet
  access, and perhaps support for everything that [Docker][docker] needs.
  - It can be behind [NAT][nat] when you use
    [Cloudflare Tunnel][cloudflare-tunnel]. A domain name is required.
- ChatGPT custom plugins (a.k.a. MCP) support `OAuth`, `Mixed`, and `None`
  authentication methods. In my case, since I am lazy, I use the `None` method
  with a long HTTP path generated by `openssl rand -hex 32` for protection. You
  can also use [Cloudflare Managed OAuth][cloudflare-managed-oauth] from
  [Cloudflare Zero Trust][cloudflare-zero-trust], or deploy your own
  [OAuth][oauth] server endpoint on your VPS.

## System Architecture

```text
You (End User)
  -> ChatGPT Chat
  -> Plugins (MCP)
  -> OpenAI's own infrastructure
  -> Cloudflare Edge
  -> Cloudflare Tunnels (Your VPS)
  -> Nginx reverse proxy
  -> OpenSandbox MCP server
  -> OpenSandbox Server
```

## Steps

### VPS Setup

The project we will use is called [OpenSandbox][opensandbox], which allows you
to deploy Dockerized sandboxes, with a shared Linux kernel similar to a
[Linux Container (LXC)][lxc], programmatically and agentically through its MCP
support.

#### Checkpoints

- Obtain a VPS.
  - This is not covered here, sorry! However, many VPS providers support free
    trials, such as [AWS][aws] (one year), [Azure][azure] (one month of credits
    and a one-year free-tier VM), [Google Cloud][gcp] (three months),
    [DigitalOcean][digitalocean] (two months), [Vultr][vultr] (one month), and
    [Linode][linode] (two months). You can also order a
    [Raspberry Pi][raspberry-pi] for your home. I use this
    [Raspberry Pi Zero 2 W][raspberry-pi-zero-2-w], but its hardware resources
    are not sufficient for multiple Dockerized applications. You can use it as
    a VPS.
- Set up basic VPS management utilities and the environment.
  - Monitoring tools ([htop][htop], [btop][btop], and [fastfetch][fastfetch])
    - We all love fancy dashboards and banners!
  - File-transfer tools ([rsync][rsync])
    - Use these in case the vibe-coded product is genuinely useful and you want
      to download it to your computer.
  - Terminal text editors ([micro][micro] and [Fresh][fresh])
    - These are for editing configuration files and environment keys.
  - Background process execution ([tmux][tmux])
    - This is for running the MCP server in the background.
  - Version control ([Git][git])

    ```bash
    git clone https://github.com/opensandbox-group/OpenSandbox --depth=1
    ```

  - Cloudflare Tunnel ([cloudflared][cloudflared])
    - This guide does not cover the traditional method, such as an
      [Nginx][nginx] reverse proxy with [SNI][sni] filtering and
      [acme.sh][acme-sh] or [Let's Encrypt][lets-encrypt] TLS certificates. :D
  - Web server ([Nginx][nginx])
    - We need Nginx for URL-path-based filtering and authentication because
      ChatGPT plugins do not support a static, unchanged
      `Authorization: Bearer` header.

![Nginx reverse-proxy configuration](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-nginx.png)

`/etc/nginx/sites-available/default`:

```nginx
server {
    listen 127.0.0.1:8081;

    location = /<your-openssl-rand-hex-32-path>/mcp {
        proxy_pass http://127.0.0.1:8000/mcp;
    }

    location / {
        return 404;
    }
}
```

- Set up [Python][python] with [uv][uv].
  - Follow the [official uv installation guide][uv-installation].
- Set up [Docker][docker].
  - Follow the [official Docker Engine installation guide][docker-installation].
- Set up the [OpenSandbox server][opensandbox-server].
  - Run `uv sync` inside `~/OpenSandbox/server`.
- Set up the [OpenSandbox MCP server][opensandbox-mcp-server].
  - Run `uv sync` inside `~/OpenSandbox/sdks/mcp/sandbox/python`.
- Configure API access keys in `.bashrc` and `.sandbox.toml`.

Fill in `[server] -> api_key`:

![OpenSandbox TOML configuration](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-sandbox_toml.png)

Fill in `OPEN_SANDBOX_API_KEY` in `.bashrc` with the same value:

![OpenSandbox API key configuration](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-open_sandbox_api_key.png)

`source ~/.bashrc`.

- Deploy.

Open two `tmux` sessions.

```console
root@OpenSandbox:~/OpenSandbox/server# uv run opensandbox-server
```

```console
root@OpenSandbox:~/OpenSandbox/sdks/mcp/sandbox/python# uv run opensandbox-mcp --transport streamable-http --api-key "$OPEN_SANDBOX_API_KEY"
```

### Cloudflare Setup

#### Cloudflare Tunnel Installation

Select `Protect and Connect -> Networking -> Tunnel`:

![Cloudflare Tunnel installation](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-cloudflare_tunnels.png)

Create a tunnel.

![Create a Cloudflare Tunnel](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-create_tunnel.png)

Follow the installation instructions to install `cloudflared` on your VPS.

Configure routes.

![Cloudflare Tunnel routes](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-routes.png)

Configure the Published Application to point to your Nginx reverse proxy.

![Published Application MCP port](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-published_application.png)

### ChatGPT Setup

First, go to [Plugins][developer-mode].

![ChatGPT Plugins screen](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-plugin.png)

Then, add a new plugin.

![Add a new ChatGPT plugin](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-plugin2.png)

Configure your plugin with the `None` authentication method, and use the long
`openssl rand -hex 32` string you generated as the HTTP path. For example:

```text
https://opensandbox-mcp.example.com/b1b823517ddb64de407ba18f8766c493097b22d8c13622f2c994710332282c57/mcp
```

![Create the ChatGPT plugin](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-create_plugin.png)

Then, enable all permissions for the AI to use the MCP server to perform
`rm -rf` on your Dockerized sandbox.

![Elevated-risk permissions](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-elevated_risk.png)

Then, check your plugin profile. You should be able to see the plugin MCP tools.

![OpenSandbox MCP tools in ChatGPT](/assets/images/2026-08-03-how-to-enjoy-chatgpt-plus-or-pro-unlimited-chat-quota-for-agentic-coding-tasks-plugin_mcp_tools_desc.png)

### Usage

## Why This Works

Because ChatGPT Chat has a virtually unlimited quota for Plus and above users.
Although you cannot launch subagents in the harness that ChatGPT Chat uses, it
is still a very powerful GPT-5.6 Sol model with `reasoning_level=high`. I would
say it is worth it.

It is quite easy to get a temporary and free VPS with sufficiently powerful
resources to run concurrent, sandboxed, and isolated agentic coding tasks while
letting your agents screw up their own development environments inside the
sandbox. Plus, sandboxes expire over time, which is configurable, so it is quite
easy to manage the garbage that your agent creates. If you do not like it, just
leave it alone, and it will eventually be gone!
